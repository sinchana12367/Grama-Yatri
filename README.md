Grama-Yatri is a Kotlin-based Android application designed to provide real-time village bus tracking for rural passengers. The app uses Firebase Realtime Database and community-driven updates to deliver accurate bus locations and ETA predictions. Built using Android Studio, it features a simple and user-friendly interface with RecyclerView integration for smooth data display. Firebase Storage and Firebase Analytics are used for data management and user activity tracking. The project aims to improve rural transportation accessibility and help passengers plan their travel efficiently.
